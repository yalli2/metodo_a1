# 듣기 파일 (Audio)

저작권 때문에 교재 MP3는 이 저장소에 포함되어 있지 않습니다. 출판사(Anaya ELE)에서 받은 파일을
이 폴더에 아래 이름으로 넣으면 각 문제의 🎧 플레이어가 자동으로 재생합니다.

- 파일 이름 규칙: `cd{CD번호}-{트랙 2자리}.mp3` → 예: `cd1-05.mp3`, `cd2-23.mp3`
- 교재의 아이콘 `1|05`는 CD 1, 트랙 5를 뜻합니다.
- 자동 정리: `python3 tools/organize_audio.py <받은폴더 또는 zip> [--cd 1]`
- 다른 이름을 쓰려면 `manifest.json`에 `{"1-05": "내파일.mp3"}` 형식으로 연결합니다.
